# 작업 상태

문서는 실제 GitHub 저장소의 코드·테스트·실행 안내를 참고하되, 이 프로젝트의 동작과 검증 결과를 기준으로 작성합니다. 개인이 직접 수행한 학습 기록은 learning_log.md에 남깁니다.
