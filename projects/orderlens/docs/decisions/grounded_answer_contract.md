# 인용 답변 계약

## 문제

검색 결과만 반환하면 호출하는 쪽이 문서 본문을 답변처럼 다시 조합하면서 출처를 빠뜨릴 수 있습니다. 반대로 문서 ID만 붙였다고 해서 그 문서가 질문에 맞는 근거라는 뜻도 아닙니다. 응답 형식의 무결성과 검색 관련성을 따로 확인할 수 있어야 합니다.

## 결정

`POST /v1/knowledge/answer`는 기존 최소 점수 정책을 통과한 1위 문서 하나만 사용합니다. 답변은 새 문장을 만들지 않고 그 문서의 본문을 그대로 반환합니다. 인용에는 다음 값을 함께 둡니다.

- `document_id`, `title`, `source`, `version`
- 답변과 같아야 하는 `quote`
- 확률이 아닌 BM25 `retrieval_score`

응답의 `mode`는 `extractive_document_quote`, 계약 버전은 `grounded-answer-v1`입니다. 기준 미달이면 `answer`는 `null`, `citations`는 빈 목록이며 보류 사유를 남깁니다. 검색 상위 문서가 틀렸을 때 그럴듯한 설명을 덧붙이지 않도록 답변 범위를 의도적으로 좁혔습니다.

## 평가

2026-10-26에 고정한 관련 질문 24개와 무관 질문 8개를 수정하지 않고 다시 사용합니다. 다음 두 종류를 구분합니다.

1. 계약 무결성: 답변에 인용이 정확히 하나 있는지, 답변과 `quote`가 같은지, 보류 응답에 답변·인용이 없는지
2. 의미 관련성: 인용한 문서 ID가 질문의 qrels에 포함되는지

고정 32문항에서 계약 오류는 0건이었습니다. 그러나 관련 질문 중 관련 문서를 인용한 답변은 15/24였고, 답변한 관련 질문만 보면 15/22였습니다. 관련 질문 2개는 보류됐고 7개는 다른 문서를 인용했으며, 무관 질문 1개에도 답했습니다. 인용 형식이 완전하다는 결과를 답변 정확도로 표현하지 않습니다.

## 남은 한계

- 답변은 문서 전문이므로 질문에 필요한 문장만 추출하거나 여러 문서를 종합하지 않습니다.
- BM25 1위가 잘못되면 답변도 잘못된 문서를 그대로 인용합니다.
- 수작업 질문과 구현자가 만든 qrels이며 실제 사용자 로그나 독립 평가가 아닙니다.
- 문서 권한, 사용자별 데이터 분리, 공개 배포 환경은 아직 다루지 않았습니다.

다음 실험은 고정 평가 문장을 튜닝에 사용하지 않고 별도 개발 질문에서 제목·본문 가중치를 정한 뒤, 같은 고정 평가로 순위 변화를 비교합니다.
