## 여기서 내린 판단

1. **AI 서비스를 만드는 역할과 모델 연구 역할을 구분해야 합니다.** 위 AI 서비스 공고는 Python 앱·RAG·API를 중심으로 설명하고, 연구·CV 사례는 석사·논문 또는 모델 전문성을 요구합니다. 모든 AI 공고가 석사를 요구한다고 일반화할 수는 없습니다.
2. **신입 표기도 기초적인 실무 증거를 요구합니다.** SQL·Python을 안다는 선언보다 정상·오류 입력을 다루는 동작, 테스트 결과, 지표 정의, 본인이 설명하는 설계가 도움이 될 것이라는 판단입니다.
3. **현재 학습을 연결할 수 있습니다.** FastAPI → DB → 적재·분석 → 검색·AI 응답 순서로 같은 제품을 확장하면 여러 도구를 배우는 이유가 구체적입니다.
4. **도구 나열을 프로젝트 목표로 삼지 않습니다.** Kafka·Spark·Kubernetes는 데이터 규모와 운영 문제가 생겼을 때 선택합니다. 초기에는 Python·SQL·API·테스트가 우선입니다.
