# 기여와 개발 기록

변경은 문제와 기대 결과를 먼저 정리한 뒤 구현합니다. 데이터 처리 결과가 달라지는 변경에는 재현 입력과 검증 결과를 함께 남깁니다.

```bash
python -m scripts.check
```

커밋 메시지에는 바뀐 동작을 적고, 설계 선택이 있으면 `docs/decisions`에 이유와 남은 제약을 기록합니다. 성능 수치는 데이터 크기·환경·실행 명령을 함께 남긴 경우에 사용합니다.

초기 구현과 문서 정리에는 Codex를 활용했습니다. v0.1.0~0.1.1의 코드 작성·실행 검증은 Codex 작업이며, 이후 직접 수정하고 확인한 내용은 `docs/learning_log.md`에 별도로 기록합니다.
