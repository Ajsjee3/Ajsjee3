실습 예제의 문장 5개는 `(5, 1024)`로 변환되었습니다. 정규화된 벡터 내적은 코사인 유사도와 일치합니다. 다만 **의미 유사도가 높다고 숫자나 사실관계까지 일치하는 것은 아닙니다.**

### 검색

강의 구현은 의미 유사도 점수와 BM25 점수를 각각 후보 집합에서 정규화한 뒤 다음 식으로 합칩니다.

```text
검색 점수 = (1 - kw) × 정규화 의미 점수 + kw × 정규화 키워드 점수
```

- `kw=0`: 의미 검색만
- `kw=0.3`: 의미 70% + 키워드 30%
- `kw=1.0`: 키워드 검색만
- `top_k=5`: 상위 5개 청크 검색

2026-11-23의 관찰은 '가온전자' 단독 질문에 `top_k=12, kw=1.0`을 사용한 것입니다. 같은 기업명이 여러 문서에 반복되므로 이 결과만으로 검색 정확도를 판단하지 않았습니다.

### 후속 평가 질문

1. 가온전자의 3분기 매출 감소 원인은 무엇인가?
2. 2분기 대비 3분기 매출액 변화는 얼마인가?
3. 3분기 재고자산과 매출채권은 각각 얼마인가?
4. 매출 감소와 물류비 상승이 영업이익에 어떤 영향을 주었는가?
5. 문서에 없는 정보를 질문했을 때 모른다고 답하는가?

### 한계와 개선 방향

- 강의 확인 질문 점수는 **기대 단어 포함 여부**를 계산합니다. 사실성·인용 정확성 전체를 자동 평가하지는 못합니다.
- 청크 크기와 중첩을 크게 한다고 언제나 정확도가 좋아지지는 않습니다.
- 금융 문서는 연도, 분기, 금액, 단위, 원가/이익 개념이 섞일 수 있어 검색 후 수치와 출처 검증이 필요합니다.
- 장차 같은 질문·같은 모델·같은 자료에서 조건을 통제해 검색 적중과 생성 품질을 비교할 계획입니다.
