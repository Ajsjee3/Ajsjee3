## 2026-11-23 — 6회차 RAG 실습

### 환경과 장애

- RTX PRO 6000 Blackwell 실습 서버를 사용했습니다.
- 대형 Qwen 모델 다운로드 시 `Disk quota exceeded (os error 122)` 오류를 경험했습니다.
- `/workspace` 전체 여유와 실제 모델 다운로드 볼륨 여유는 다를 수 있습니다. 강의 조절판에 다운로드 볼륨 여유 약 9GB가 표시되어 14B 파일(강의 추정 약 33GB)을 받을 수 없었습니다.
- GPU VRAM이 충분해도 디스크 저장 한도가 부족하면 모델을 내려받지 못한다는 점을 확인했습니다.

### 금융 문서 RAG

- 가온전자 2026년 2·3분기 실적, 재무 위험 문서 3건을 초기 재료로 구성했습니다.
- 주제 확장을 위해 경영실적·지역별 매출·재고·매출채권·물류·공급망 등에 관한 합성 문서 25건을 추가로 준비했습니다.
- 검색 패널에는 확장 문서 제목들이 나타났지만, 서버에 최종 등록된 파일 수는 아직 숫자로 검증하지 않았습니다.
- 실제 기업 공시가 아닌 가상의 데이터입니다.

### 청킹·임베딩

- 문장 경계 청킹은 문장마다 한 파일로 만드는 것이 아니라 문장 경계를 보존하며 글자 수 제한까지 묶는 방식입니다.
- 고정 길이 청킹은 문장을 중간에 끊을 수 있고, overlap은 앞 청크 끝부분을 다음 청크에 반복합니다.
- `lab.embed(sents)`로 5개 문장을 임베딩해 `(5, 1024)` 배열을 확인했습니다.
- `v @ v.T`를 통해 문장 간 코사인 유사도 행렬을 실험했습니다.

### 검색·해석

- `lab.search_panel()`에서 질문 `가온전자`, `top_k=12`, `kw=1.0` 조건의 결과를 확인했습니다.
- `kw=1.0`은 키워드 중심 검색이며, 의미 점수가 높은 문서가 순위에서 밀릴 수 있습니다.
- 회사명만 검색하면 많은 문서에 같은 단어가 있어 검색의 적절성을 평가하기 어려웠습니다.
