# 재무 자료

서비스는 `samsung/`의 두 문서만 색인합니다. 삼성전자 뉴스룸의 2024년 2·3분기 확정 실적 발표를 읽고 전사 연결 실적, DS 부문 실적, 회사가 설명한 변동 요인을 한국어로 요약했습니다. 금액 단위는 조 원입니다. 아래 링크와 발표일은 API의 각 검색 결과에서도 확인할 수 있습니다.

| 기간 | 발표일 | 연결 매출 | 연결 영업이익 | 공식 자료 |
|---|---|---:|---:|---|
| 2024년 2분기 | 2024-07-31 | 74.07 | 10.44 | [삼성전자 실적 발표](https://news.samsung.com/kr/삼성전자-2024년-2분기-실적-발표) |
| 2024년 3분기 | 2024-10-31 | 79.10 | 9.18 | [삼성전자 실적 발표](https://news.samsung.com/kr/삼성전자-2024년-3분기-실적-발표) |

`sources.json`의 키는 문서 파일의 확장자를 뺀 이름입니다. 원문 주소와 발표일을 청크와 별도로 보관해 문장이 나뉘어도 출처를 찾을 수 있습니다. 이 자료는 재현을 위해 고정한 과거 분기 데이터입니다.

`sample/`에는 6회차에 사용한 가상 기업 문서가 학습 이력으로 남아 있습니다.
