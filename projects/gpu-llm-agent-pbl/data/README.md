# FinanceRAG 데이터 설명

이 데이터는 실제 금융 공시가 아니라, **가상 전자부품 기업 ‘가온전자’에 대해 구성한 합성 실습 자료**입니다. 투자 의사결정에 사용하지 마세요.

현재 GitHub에는 **초기 재무 문서 3건의 정리본**을 포함합니다. 추가로 작성·실험한 25건의 확장 문서는 추후 버전과 등록 상태를 확인해 업데이트할 예정입니다. 강의 서버에 올린 파일과 GitHub에 업로드한 파일은 구분합니다.

| 지표 | 2026년 2분기 | 2026년 3분기 |
|---|---:|---:|
| 매출액 | 1,200억 원 | 1,050억 원 |
| 영업이익 | 110억 원 | 70억 원 |
| 현금성 자산 | 260억 원 | 210억 원 |
| 매출채권 | 270억 원 | 340억 원 |
| 재고자산 | 190억 원 | 230억 원 |

강의 노트북 `lab.docs_panel()`의 '파일 올리기(.txt · .md)'에서 문서를 선택하여 사용할 수 있습니다.

이 폴더의 내용은 개인 RAG 검색 실습을 위한 합성 문서입니다.
