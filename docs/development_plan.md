# 포트폴리오 개발 계획

대표 프로젝트: `projects/orderlens`

2026-09-22에 제공된 취업 준비 대화와 [커리큘럼을 비교](curriculum_alignment.md)했습니다. OrderLens에서 Python·SQL·실제 데이터 처리·백엔드 기초를 먼저 완성합니다. 두 번째 금융 공시 프로젝트는 직접 실행·수정·설명하는 기준을 통과한 뒤 선택합니다. 학습 시간은 주 6~10시간을 유지합니다.

한 번에 기능 하나를 구현하고, 필요한 검증과 문서를 함께 반영합니다. 이미 열린 변경이 있으면 먼저 마무리하고 다음 작업으로 넘어갑니다.

| 순서 | 작업 | 완료 기준 |
|---|---|---|
| 완료 | 판매 경로별 지연 주문 | 조회 한도·최신 상태·시간 경계를 함께 검증 |
| 완료 | 상태별 주문 목록과 페이지 처리 | 고정 데이터의 정렬·페이지 경계 검증, 과거 데이터 추가 시 한계 재현 |
| 완료 | PostgreSQL 통합 및 마이그레이션 | PostgreSQL 16에서 적재·재전송·집계·페이지 조회와 마이그레이션 왕복 확인 |
| 완료 | 실제 공개 데이터 변환 | UCI CSV 출처·이용 조건·필드 매핑·전체 정제와 반복 결과 기록 |
| 완료 | 공개 거래 전용 DB 적재 | GBP·소수 금액 보존, 파일 해시·행 번호 제약, 같은 파일 재적재 검증 |
| 1 | SQL 실행계획과 성능 | 데이터 규모와 동일 조건의 전후 측정 |
| 2 | 배치 실패·재시도·관측 | 강제 실패 후 중복 없는 복구와 오류 기록 |
| 3 | 검색 평가 확대 | 별도 질문 집합, 실패 사례, 기준선 비교 |
| 4 | 근거를 인용하는 답변 | LLM 사용 시 비용 설정, 근거 부족 응답, 평가 |
| 5 | 서비스 운영 | 배포 환경, 권한, 복구와 실제 피드백 |

README는 구현한 문제와 결과를 구체적으로 설명합니다. 직접 수행한 학습 기록은 프로젝트의 learning_log.md에 남깁니다. 참고 대상은 공개 저장소의 코드·테스트·실행 안내이며, 취업 후기나 확인되지 않은 합격 여부를 프로젝트의 근거로 사용하지 않습니다.

반복 개발 작업을 2026-09-09에 등록했습니다. 첫 예정일은 2026-09-14이며 매주 월요일 저녁, 한국 시간 기준으로 실행하도록 설정했습니다. 최신 상태는 docs/portfolio_status.json과 GitHub 이슈·변경 기록을 읽고 판단합니다. 사용자가 취업 완료 또는 중단을 알리면 반복 작업을 일시 중지합니다. 자동 지원서 제출은 이 개발 작업에 포함되지 않습니다.

2026-09-14: [주문 목록·페이지 조회 이슈](https://github.com/Ajsjee3/Ajsjee3/issues/1)의 구현과 로컬 검증을 완료했습니다. 설계와 재현 조건은 [페이지 조회 결정 기록](../projects/orderlens/docs/decisions/order_pagination.md)에 남겼습니다.

2026-09-21: Alembic 초기 리비전과 PostgreSQL 16 전용 통합 검사를 구현했습니다. 로컬 SQLite와 [GitHub Actions의 PostgreSQL 16.15](https://github.com/Ajsjee3/Ajsjee3/actions/runs/35590864397)에서 upgrade·downgrade·재upgrade를 확인했습니다. PostgreSQL에서는 합성 데이터 적재·재전송, 지표와 페이지 조회도 통과했습니다.

2026-09-28: 이전 미완료 공개 거래 정제 작업을 마무리합니다. 원본 541,909행을 정제하고 음수 단가 2행을 별도 기록했습니다. 공개 거래는 기존 원화 배송 주문과 의미가 달라 아직 주문 API·DB에 연결하지 않았습니다. 다음 작업은 전용 테이블과 재적재 방지입니다.

2026-10-05: 공개 거래의 출처 파일과 정제 행을 분리한 두 테이블, 두 번째 Alembic 리비전, 트랜잭션 적재와 파일 단위 재적재 방지를 구현했습니다. 전체 541,907행을 임시 SQLite에 넣고 같은 파일의 두 번째 실행에서 새 행 0개를 확인했습니다. PostgreSQL에서는 PR의 작은 합성 입력으로 NUMERIC 정밀도·UNIQUE 제약·재적재를 검사합니다.

최근 채용 공고 검토일은 2026-09-22입니다. 원문과 모집 상태는 프로젝트의 market_review.md, 실제 GitHub 파일 참고 내용은 references.md에 기록했습니다. 코드 구현과 본인 학습 완료는 별개이며 현재 학습 상태는 미평가입니다.
