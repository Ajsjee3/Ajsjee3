# 포트폴리오 개발 계획

대표 프로젝트: `projects/orderlens`

한 번에 기능 하나를 구현하고, 필요한 검증과 문서를 함께 반영합니다. 이미 열린 변경이 있으면 먼저 마무리하고 다음 작업으로 넘어갑니다.

| 순서 | 작업 | 완료 기준 |
|---|---|---|
| 완료 | 판매 경로별 지연 주문 | 조회 한도·최신 상태·시간 경계를 함께 검증 |
| 1 | 상태별 주문 목록과 페이지 처리 | 정렬 규칙, 마지막 페이지, 중복·누락 사례 확인 |
| 2 | PostgreSQL 통합 및 마이그레이션 | 실제 DB에 적재·재전송·집계 실행, 스키마 변경 기록 |
| 3 | 실제 공개 데이터 변환 | 이용 조건·출처·필드 매핑·품질 결과 기록 |
| 4 | SQL 실행계획과 성능 | 데이터 규모와 동일 조건의 전후 측정 |
| 5 | 검색 평가 확대 | 별도 질문 집합, 실패 사례, 기준선 비교 |
| 6 | 근거를 인용하는 답변 | LLM 사용 시 비용 설정, 근거 부족 응답, 평가 |
| 7 | 서비스 운영 | 배포 환경, 오류 관측, 복구와 실제 피드백 |

README는 구현한 문제와 결과를 구체적으로 설명합니다. 직접 수행한 학습 기록은 프로젝트의 learning_log.md에 남깁니다. 참고 대상은 공개 저장소의 코드·테스트·실행 안내이며, 취업 후기나 확인되지 않은 합격 여부를 프로젝트의 근거로 사용하지 않습니다.

반복 개발 작업을 2026-09-09에 등록했습니다. 첫 예정일은 2026-09-14이며 매주 월요일 저녁, 한국 시간 기준으로 실행하도록 설정했습니다. 최신 상태는 docs/portfolio_status.json과 GitHub 이슈·변경 기록을 읽고 판단합니다. 사용자가 취업 완료 또는 중단을 알리면 반복 작업을 일시 중지합니다. 자동 지원서 제출은 이 개발 작업에 포함되지 않습니다.

다음 구현의 완료 기준은 [주문 목록·페이지 조회 이슈](https://github.com/Ajsjee3/Ajsjee3/issues/1)에 정리했습니다.
